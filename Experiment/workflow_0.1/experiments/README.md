# workflow_0.1 experiments

这里放所有基于 `workflow_0.1` 策略跑出来的实验。

推荐每个实验目录使用：

```text
exp_001_实验主题/
├── README.md
├── code_notes/
├── config/
├── outputs/
├── submission/
└── review/
```

## 每个实验至少记录

- 实验目的：验证 workflow_0.1 里的哪个判断。
- 代码来源：使用 `Baseline `、`THU-BDC2026-main`、`bigdata_challenge` 或其他脚本的哪一部分。
- 数据来源：使用哪份 train/test、哪份抓取数据、哪份特征表。
- 关键改动：本次和上一次实验相比改了什么。
- 输出结果：候选池、`result.csv`、评分或人工观察。
- 结论：继续保留、需要修改、还是放弃这一方向。
