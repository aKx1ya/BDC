# 流程修改想法

这个文件只记录我们当前对核心流程 Step-1 和 Step-2 的修改想法。

核心出发点：

```text
我们觉得原来的 Step-1 / Step-2 太重、太冗余。
新的 baseline 应该更贴近比赛的 5 日持有期。
先围绕：板块趋势、个股趋势、交易量/成交额。
```

---

## Step-1：数据获取

Step-1 的核心想法：

```text
Step-1 只负责拿数据，不在这里直接筛股票。
数据要干净、可复现、预测日T当天真实可得。
```

### 1. 保留基础价量 daily raw data

虽然最终提交后看的是未来 5 个交易日收益，但这里不建议直接把原始数据变成 5 日频率。

我们的想法是：

```text
Step-1 保留 daily 原始数据
Step-2 再基于 daily 数据计算 5 日特征
```

原因：

```text
如果只保留5日数据，会丢掉五天内部路径。
比如中途大跌、放量冲高回落、突然缩量、流动性枯竭。
这些信息后面做趋势判断和风险过滤时仍然有用。
```

第一版基础字段：

```text
open
close
high
low
volume
amount
turnover
pct_chg
```

如果使用中文字段，对应为：

```text
开盘
收盘
最高
最低
成交量
成交额
换手率
涨跌幅
```

### 2. 板块/行业数据

这是我们这版 baseline 的核心新增方向。

我们现在讨论的关键问题是：

```text
什么是强势板块？
怎么判断一个板块真的有上涨趋势？
能不能先给板块排序，再进入强势板块内部继续选股？
```

在判断强势板块之前，我们需要先定义股票被分到哪些板块。

第一版先不使用过细的申万一级行业直接排序，而是先把行业归并成几个更适合沪深300的风格板块：

```text
消费：
食品饮料、家用电器、医药生物、农林牧渔、社会服务、美容护理、纺织服饰、轻工制造、商贸零售

科技（TMT）：
电子、计算机、传媒、通信

金融地产：
银行、非银金融、房地产

周期：
有色金属、基础化工、石油石化、钢铁、煤炭、建筑材料

制造：
电力设备、机械设备、国防军工、汽车

基建与公用：
公用事业、交通运输、建筑装饰、环保
```

这样做的原因：

```text
1. 沪深300股票数量有限，行业太细会导致每个行业样本过少。
2. 六大风格板块更适合先做大方向判断。
3. 后续可以先排序这些风格板块，再进入板块内部选个股。
4. 这种划分也更容易解释：先看市场风格，再看个股强弱。
```

第一版板块判断顺序：

```text
先把每只股票映射到六大风格板块
再计算每个风格板块最近的整体表现
再判断哪些风格板块属于强势板块
最后再进入强势板块内部看个股
```

第一版数据口径先用“自聚合行业”：

```text
个股 daily 行情
+ 个股所属板块/行业映射
= 我们自己聚合出来的板块表现
```

也就是说，一个板块强不强，不先靠主观判断，而是看这个板块内部股票最近的整体表现。

Step-1 需要收集：

```text
股票属于哪个板块/行业
板块或行业的成分关系
个股 daily 行情
```

后续在 Step-2 中，再基于这些数据计算板块分数。

我们目前可以讨论三种“强势板块”定义方法：

```text
方法一：趋势优先法
主要看板块近5日、近10日收益。
优点是简单直接，贴近“上涨趋势”的直觉。
缺点是容易追高。

方法二：均衡三因子法
同时看板块收益、成交额放大、板块内部上涨家数。
也就是：最近涨、有量、不是少数股票硬拉。
这是第一版最值得优先讨论的方法。

方法三：风险调整法
看板块收益是否足够稳定，避免只买高波动冲高的板块。
优点是更稳。
缺点是可能错过短期爆发板块。
```

第一版我们更倾向先讨论：

```text
均衡三因子法
```

原因：

```text
我们想找的强势板块，不只是涨幅最高。
更应该是：
最近上涨
成交额放大
板块内部多数股票一起走强
```

注意：

```text
板块信息也要尽量保证预测日T可得。
不能用未来才知道的板块成分或事件信息去回测过去。
```

### 3. 交易量 / 成交额

交易量和成交额在 Step-1 先作为 raw data 保留。

想法：

```text
趋势必须有量能确认。
上涨但没有成交额支持，可能只是噪声。
成交额太低的股票，也不适合进入候选池。
```

### 4. 目前先不放入第一版的数据

这些想法先记录，但不作为第一版 Step-1 的核心输入：

```text
政策信息
期权费映射
负相关资金流
新闻文本
舆情
北向资金
龙虎榜
融资融券
```

原因：

```text
这些数据复杂度高。
时间戳和可得性不好控制。
容易引入未来信息泄漏。
第一版 baseline 先不要变得太重。
```

## Step-2：特征工程与初步筛选想法

Step-2 的核心想法：

```text
Step-2 把 Step-1 的 daily raw data 转成更贴近 5 日持有期的特征。
不要堆很多技术指标。
第一版只围绕：板块趋势、个股趋势、量能确认、基础风险。
```

### 1. 板块趋势

我们希望先判断：

```text
哪些风格板块最近处于上涨趋势？
哪些风格板块同时有成交额放大？
哪些风格板块内部不是只有一两只股票在涨？
```

这里我们先建立一个“短线板块打分卡”。

第一版原则：

```text
只使用可以从 daily 行情和已知事件中稳定得到的数据。
先不把主力资金、北向资金放进核心权重。
```

短线板块打分卡满分 100 分：

```text
一、短期动量：45分
1. 近5日累计涨跌幅：20分
   在六大风格板块中排名。
   第1名20分，第2名16分，第3名12分，第4名8分，第5名4分，第6名0分。

2. 近5日超额收益 vs 沪深300：15分
   计算：板块近5日收益 - 沪深300近5日收益。
   同样在六大风格板块中排名给分。
   目的是判断板块是不是真的强于大盘。

3. 短期均线多头形态：10分
   5日均线在10日均线之上，且今日收盘价在5日均线之上：10分
   只满足一个条件：5分
   均线缠绕或空头：0分

二、量能确认：25分
1. 成交额环比放大程度：15分
   计算：板块近5日日均成交额 / 板块近20日日均成交额。
   比值 > 1.3：15分
   1.0 到 1.3：8分
   < 1.0：0分

2. 板块近5日成交额横向排名：10分
   在六大风格板块中比较近5日平均成交额。
   成交额越活跃，得分越高。
   目的是确认上涨是否有资金参与。

三、情绪与扩散：20分
1. 板块内创20日新高个股占比：10分
   统计板块内收盘价创近20日新高的股票占比。
   占比越高，说明赚钱效应越扩散。

2. 近5日涨幅大于5%的个股占比：10分
   统计板块内近5日累计涨幅超过5%的股票占比。
   占比越高，说明板块攻击力越强。

四、短期催化剂：10分
1. 未来5天事件评分：10分
   强催化：10分
   一般催化：5分
   无或不明：0分

   催化剂必须在预测日T之前已经知道。
   不能评分后再补理由。
```

板块短线总分：

```text
板块短线总分 =
    短期动量
  + 量能确认
  + 情绪与扩散
  + 短期催化剂
```

第一版用法：

```text
先计算六大风格板块各自的短线总分。
再按总分从高到低排序。
优先进入总分靠前的强势板块内部选股。
```

增强版暂缓指标：

```text
近5日主力资金净流入强度
近5日北向资金净流入强度
```

暂缓原因：

```text
当前这两类数据不一定有稳定的历史板块级序列。
如果直接加入第一版，可能导致无法回测，或者引入未来信息泄漏。
等数据可以稳定按预测日T对齐后，再加入增强版打分卡。
```

### 2. 个股 Trend

因为我们最终提交后中途不会换手，所以更关注短期趋势是否能延续 5 个交易日。

可以考虑的特征：

```text
ret_5：个股近5日收益
ret_10：个股近10日收益
ma5_over_ma20：MA5 / MA20 - 1
trend_slope_5：近5日收盘价趋势斜率
stock_vs_sector_ret_5：个股近5日收益 - 所属板块近5日收益
rank_in_sector_ret_5：个股近5日收益在板块内排名
```

第一版最核心：

```text
ret_5
trend_slope_5
stock_vs_sector_ret_5
rank_in_sector_ret_5
```

### 3. 交易量 / 成交额确认

趋势要配合量能确认。

可以考虑的特征：

```text
amount_ma5：近5日平均成交额
amount_ratio_5_20：近5日成交额 / 近20日成交额
volume_ratio_5_20：近5日成交量 / 近20日成交量
amount_rank_5：近5日成交额在横截面中的排名
```

第一版最核心：

```text
amount_ratio_5_20
volume_ratio_5_20
amount_rank_5
```

### 4. 基础风险过滤

这里不是为了预测收益，而是为了先排除不适合进入候选池的股票。

可以考虑：

```text
近3日平均成交额过低：剔除
近20日最大回撤过大：剔除或降权
近20日出现极端单日大跌：剔除或降权
停牌、无成交、价格异常：剔除
```

### 5. Step-2 的第一版输出

Step-2 不直接生成最终 `result.csv`。

第一版输出应该是：

```text
轻量特征表
板块趋势分数
个股趋势分数
量能确认分数
基础风险标记
```

这些输出只作为后续流程的输入，这里不继续展开后面的 step。

```text
后续流程输入
```

## 当前一句话版本

```text
我们不再让 Step-1 / Step-2 变成大而全的数据和特征堆叠；
第一版只保留 daily 基础价量和板块映射，
再在 Step-2 计算围绕 5 日持有期的板块趋势、个股趋势、量能确认和基础风险特征。
```
